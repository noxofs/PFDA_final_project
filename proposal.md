## Description
A tool for color blind artist that assists in awareness of what color is being used through mathematical conversions. It will be relevant to digital arts as there are plenty of colorblind individuals (no matter which kind) out there who want to be able to create art, but might feel setback from their disability.

## Features
- Hex to RGB/HSV converter
	- I will show the math behind each color value and the percentage of R/G/B within a hex code
- Color square
	- I will include a display of the current color with the hex code as user input
- Color Harmonies
	- I will calculate different color harmonies based on the input (complementary, analogous, etc.)

## Challenges
- Learn how to convert Hex codes to RGB
- Learn how to calculate color palettes based on hex code or RGB
